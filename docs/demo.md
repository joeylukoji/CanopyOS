# 60–90 second demo

Use the [product gallery](demo-gallery.md) and its credited sample photographs
when showing the workflow without a live outdoor location.

1. **0–10s:** Show the real outdoor scene. “Cities need more nature. Where could we start?”
2. **10–25s:** Open CanopyOS on a phone over HTTPS. Capture a wide view and inspect the preview.
3. **25–45s:** Show genuine processing steps, then original and segmentation images.
4. **45–60s:** Explain the pixel metrics and the exploratory Green Score.
5. **60–75s:** Show the selected intervention, provider provenance and explanation.
6. **75–90s:** “CanopyOS turns every walk into climate data.” Explain the need for a site survey.

Only say “Jev selected” when the report source is `jev`. Only say “Gemma explained”
when it is `gemma`. If a fallback was used, identify it explicitly. Never describe
the candidate-ground overlay as a climate simulation or guaranteed future result.

Before presenting: warm the real model, verify credentials, capture a real field
scan and rehearse on the presentation network. Save a clearly-labelled previously
computed scan as backup. Record your own screen walkthrough for the submission.
